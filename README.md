Pro AI Tutor
A modern AI-powered study assistant that analyzes PDFs, provides interactive chat, and generates automated quizzes to test your knowledge.
Features
* **PDF Analysis**: Upload your study materials and get instant summaries.
* **Interactive AI Chat**: Ask questions about your documents in real-time.
* **Smart Quizzes**: Automatically generates questions to help you prepare for exams.
* **Professional UI**: Built with a clean, user-friendly interface using PyQt6.
nstallation
1. Clone the repository.
2. Install the dependencies:
   `pip install -r requirements.txt`
3. Add your OpenAI API key to a `.env` file.
4. Run the app:
   `python main.py`
